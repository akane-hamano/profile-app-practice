# profile-app-practice

## 概要

COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。
コントローラーで固定データを準備し、Bladeビューに渡して表示する「自己紹介ページ」を作成しました。

## 使用技術

- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと

- ルーティング → コントローラー → ビューのLaravelの基本の流れ
- コントローラーの作成
- ルーティングの定義
- ビューの作成

## 動作確認

ブラウザで http://localhost/profile にアクセスし、自己紹介ページが表示されれば成功です。
